Summarize Your Emails

Call a local Python function to load your inbox, inject the results into a prompt, and get a categorized summary — in a single @effect run.

Margarita
summarize-emails.mgx
from src.applemail import load_emails

@effect func load_emails(limit=20) => result

<<
Summarize the last 20 emails I've gotten.

- Categorize them.
- Give me an action item list.
- Ignore spam type emails.

Here are the emails:
${result}
>>

@effect run

src/applemail.py

Reads the Apple Mail Envelope Index via SQLite and returns a list of Email objects. Called directly by @effect func — no API wrapper needed.

from dataclasses import dataclass
from datetime import datetime
from pathlib import Path
import sqlite3, glob

MAIL_BASE = Path.home() / "Library" / "Mail"
# Apple Mail stores dates as seconds since 2001-01-01
MAC_EPOCH_OFFSET = 978307200

@dataclass
class Email:
    message_id: str
    subject: str
    sender: str
    recipients: list[str]
    date: datetime | None
    mailbox: str

def load_emails(limit: int = 100) -> list[Email]:
    """
    Query the Apple Mail Envelope Index for the most recent emails.
    Requires Full Disk Access for your terminal in System Settings.
    """
    index_path = _find_envelope_index()
    conn = sqlite3.connect(f"file:{index_path}?mode=ro", uri=True)
    conn.row_factory = sqlite3.Row

    rows = conn.execute("""
        SELECT m.ROWID, m.message_id,
               COALESCE(su.subject, CAST(m.subject AS TEXT)) AS subject,
               m.date_sent, m.flags,
               s.address AS sender_address, s.comment AS sender_name,
               mb.url AS mailbox_url
        FROM messages m
        LEFT JOIN subjects su ON m.subject = su.ROWID
        LEFT JOIN addresses s ON m.sender = s.ROWID
        LEFT JOIN mailboxes mb ON m.mailbox = mb.ROWID
        ORDER BY m.date_sent DESC LIMIT ?
    """, (limit,))

    return [_row_to_email(conn, row) for row in rows]

pyproject.toml

The only dependency is emlx — a small library for reading Apple Mail .emlx files. Install with uv sync.

[project]
name = "summarize-emails"
version = "0.1.0"
requires-python = ">=3.12"
dependencies = [
    "emlx>=1.0.4",
]

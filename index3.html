Margarita

Writing agents should be as easy as writing markdown.

Margarita turns Markdown scripts into full agentic workflows. Declare variables, call your LLM, and pass results between steps — all in files you can read and understand at a glance.

Get Started → GitHub
review.mgx
// This is a margarita script (.mgx) // These are variables @state score = 0 @state feedback = "" // Add Markdown and fill in the vars << The current score is ${score}. Review this code snippet and set `score` to a number from 0–100 and `feedback` to a one-sentence summary of the quality. ```python def add(a, b): return a+b ``` >> // This runs the agent. The agent updates the vars @effect run << Explain the score of ${score} in more detail and tell me about the feedback. >> // Now we take the results and run again! @effect run

Why Margarita

01

Use any model, on any backend

Run the same script against Copilot, Llama (adding more). Your script stays exactly the same.

margarita use ollama
02

Control your context, keep costs low

Most AI code harnesses hide the context from you. Margarita gives you complete control. Add only the tools you need. Run Python functions locally and update the context.

@effect context clear
03

Compose prompts from reusable .mg files

Write a reusable prompt component and reuse it your other scripts. Need to change it across your org? Just update it in one spot.

[[ role.mg ]]
